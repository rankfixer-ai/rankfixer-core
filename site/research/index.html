Scoring Methodology

Each domain was scored across six signals, weighted to produce a 0-100 score:

SignalWeightWhat it measures
Schema completeness25%JSON-LD structured data (Organization, FAQPage, Article, etc.)
Entity consistency20%@id linkage, sameAs links, brand definition, OG/Twitter meta
Content structure20%Substantial text, FAQ-style questions, lists/tables, meta description
Technical structure15%H1/H2 hierarchy, nav/main landmarks, microdata
Crawlability10%AI crawler access via robots.txt
llms.txt10%Dedicated llms.txt file for AI crawler discovery

The engine fetches each domain's homepage, robots.txt, and llms.txt. The scoring code and raw dataset are open source (MIT) on GitHub.

Key Findings

Schema is the biggest gap

The average schema score was 26.6/100 — by far the weakest signal. Most sites either have no structured data or use it inconsistently. Adding FAQPage + Organization schema is the single highest-impact fix.

llms.txt is becoming standard

72% of the domains we scanned publish one. It is cheap to add and directly signals AI crawlers. Use our free validator to check yours.

Blocking AI crawlers is a real problem

9 of the 100 domains we attempted were bot-blocked (403/406/429) and could not be scored. If your robots.txt blocks GPTBot and friends, you are invisible by choice.

Each AI engine has different citation standards

ChatGPT rewards authority, Perplexity rewards freshness + attribution, Claude rewards structured data, and Gemini rewards entity clarity. Optimizing for one does not optimize you for all.
